### 🚀 Project Source Code Directory

Welcome to the project repository overview. To keep our architecture clean and modular, the system is split into two dedicated repositories. 

Please click the links below to access the frontend and backend source code instantly. 

### 📂 Repository Links

### [🎨 Frontend Repository](https://github.com/Lychuss/yes-park-cafe-frontend)

* **Tech Stack:** React, Tailwind CSS, Next JS
* **Description:** Contains the user interface, UI components, and client-side routing.

### [⚙️ Backend Repository](https://github.com/Lychuss/yes-park-cafe-backend)

* **Tech Stack:** Node.js, Express, PostgreSQL, Supabase
* **Description:** Contains the REST API, database schemas, authentication logic, and server configurations, with xendit payment gateway.

### 🛠️ Local Development Quick Start

If you want to spin up both projects locally at the same time: 

1. **Clone the frontend:** git clone https://github.com/Lychuss/yes-park-cafe-frontend
2. **Clone the backend:** git clone https://github.com/Lychuss/yes-park-cafe-backend
